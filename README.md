# Lucent

A minimal, private budget tracker for Android. Everything you enter stays on your phone; the app never uses the internet.

## Status

Planning done, app code not written yet. This file will explain every part of the code in plain English as it's added.

## What's here

- `docs/SUMMARY.md`: a one-page plain-language description of the full Lucent idea.
- `docs/SPEC.md`: the detailed spec for the bigger multi-platform version. The current plan is a smaller Android-only version: setup with your own categories, adding income and expenses, a transaction list, monthly category budgets, a home summary, and settings.
